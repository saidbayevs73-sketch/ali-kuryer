# Ali Kuryer Android

Ali Kuryer — Android ilovasi prototipi (Kotlin + Jetpack Compose).

## Build APK
GitHub Actions orqali `Build Ali Kuryer APK` workflow ishga tushiriladi. Natijada `AliKuryer-debug-apk` nomli artifact hosil bo‘ladi.

## Hozirgi imkoniyatlar
- Onboarding va til tanlash
- Telefon raqami va demo OTP ekrani
- Bosh sahifa, restoran, savat
- Manzil va to‘lov bosqichi (naqd pul)
- Buyurtma muvaffaqiyati, kuzatish, buyurtmalar va profil

## Cheklovlar
Bu hozircha UI/prototip. Haqiqiy SMS tasdiqlash, server, restoran katalogi API, GPS, kuryer dispetcherligi, push xabarnomalar va to‘lov provayderlari ulanmagan. Onlayn karta to‘lovi keyingi bosqichga qoldirilgan.
