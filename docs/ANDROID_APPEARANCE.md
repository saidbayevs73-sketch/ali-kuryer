# Android appearance: light, dark and system

Mijoz ilovasi: Profil → Ko‘rinish → Oq fon / Qora fon / Avtomatik.
- Default avtomatik: telefonning qorong‘i yoki yorug‘ rejimiga mos.
- Tanlov Android SharedPreferences'da saqlanadi va ilovani qayta ochganda ham qoladi.
- Matnlar, fon, kartalar, navbatdagi menyular va tizim status panellari moslashadi.
- Real taom fotosuratlari rejim bilan rangini o‘zgartirmaydi.
- Bu faqat ilova UI. Ishlab turgan Render saytlari, mijozlar bazasi, to‘lovlar va SMS sozlamalari o‘zgartirilmaydi.
- Release oldidan haqiqiy qurilmada yorug‘, qorong‘i va tizim rejimlarini, barcha foydalanuvchi rollarini va kirish/buyurtma oqimini ko‘zdan kechirish kerak.
